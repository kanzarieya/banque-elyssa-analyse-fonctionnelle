**Ce que le lecteur doit en retenir :** la cause racine n'est pas l'absence d'outil mais
l'absence de **référentiel de complétude** — rien ne définit ce qu'est un dossier complet.
C'est elle qui produit les 35 % de dossiers incomplets.

| Fichier | À quoi il sert |

| [to-be-processus.md](to-be-processus.md) | Douleur par douleur, ce que le TO-BE change ; [diagramme BPMN](to-be-processus.png) ; délais ciblés ; ce qui ne change pas et pourquoi |

la déclinaison mobile du portail client est planifiée au Sprint 1 (ENF-04).
